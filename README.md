# 🍔 Food Shop Website

This is a responsive fast food shop website built with HTML and CSS. It features a clean layout, accessible navigation, and a structured food menu.

🔗 **Live Demo:** [View Website](https://mustafa-sarwari.github.io/Food-Shope-Website/)

## 📌 Features

- Fully responsive design for desktop and mobile
- Semantic HTML structure with accessibility best practices
- Fixed navigation with anchor links
- Image with caption and alternative text
- Table-based food menu with `thead`, `tbody`, and `tfoot`
- Footer with copyright

## 🛠️ Technologies Used

- HTML5
- CSS3
